# 界面

页面使用 React、Mantine、Tabler 图标和 CSS。首页采用暖白背景，放映室使用深色背景，影片是主要内容。

- `implemented-home.png`、`implemented-room.png`、`implemented-mobile.png`：当前版本的实际页面。银幕中的条码是同步测试片。
- `website-room-desktop.png`、`website-room-mobile.png`：当前网站模式的实际页面。
- [INTERACTION.md](INTERACTION.md)：布局、操作和状态说明。

界面以键盘和触控操作为基础，主要按钮至少 44px，遵循系统的减少动态效果设置。
