# Design assets and provenance

The built-in image generation tool produced these original assets. Model selection is managed by the tool; no unverified model name is claimed.

- `public/art/train.webp`: atmospheric forest railway art. Source PNG is retained locally under the same directory (ignored by Git); the WebP is distributed with the site.
- `public/art/desert.webp`: speculative desert observatory art, same provenance.
- `screening-concept.png`: product-design reference for layout and visual hierarchy. This is a generated design study, not a screenshot or proof of implementation.
- `implemented-home.png`: actual browser screenshot of the implemented app, distinct from the generated study.
- Actual browser screenshots are generated under the ignored `artifacts/` directory by Playwright.

Only lossless-to-WebP delivery conversion was applied to the art. The site uses CSS object-fit for layout cropping; it does not present the decorative art as actual films or available movie sources.

## Prompts

### Forest railway

Use case: photorealistic-natural. Asset type: original portrait 2:3 decorative cinema art card, not an actual film advertisement. A solitary warmly lit vintage railway carriage winding through a forest of tall dark cypress trees at dusk, amber windows, deep moss green and muted ochre, poetic dramatic soft light, slightly aerial view, rich analog 35mm film grain, premium independent cinema photography with precise architectural detail. Elegant quiet mysterious storytelling composition. No typography, no text, no existing characters, no logos, no watermark, no borders.

### Screening page design study

Use case: ui-mockup. Asset type: high fidelity desktop web app product design reference for a Chinese private watch-party app called 幕间 INTERLUDE. Create a polished 1440x1000 desktop browser app screenshot, dark Apple-level restrained premium design. Top left original minimal double-slash sage green logo and 幕间, right small private-room badge. Main heading 今晚的放映. Large video player occupies left 73 percent, cinematic misty blue ocean cliff and warm tiny cabin in the video frame. Slim play pause seek controls beneath. Right 27 percent elegant chat sidebar tabs 聊天 and 座位 with two tasteful messages and a single-line message input at bottom. Invite friend button 邀请朋友 top right, microphone and settings icons, muted charcoal green palette with warm off-white type, sage accents, generous space, impeccably aligned typography, 12px subtle rounded corners, hairline borders, no neon gradients. Main screen should feel like a thoughtfully designed real shipping product, calm cinema ambience, clearly legible beautiful Chinese interface. No existing trademarks or Apple logos. Original UI design study, not a real screenshot.
