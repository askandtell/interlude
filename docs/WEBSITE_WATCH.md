# 视频网站一起看（实验性）

视频网站模式让每个人在官方网站播放自己的视频，一起看同步播放位置、暂停和跳转，文字聊天留在房间。每个人需要各自拥有观看权限。

## 使用

1. 房主创建房间，点击播放器上方「使用视频网站一起看」，粘贴官方桌面版播放页链接。朋友仍须通过邀请和房主审批。
2. 每人点击「打开官方播放页」，使用自己的账号及相应观看权限。无扩展时可按房间时间手动对齐。
3. 自动同步需要 Chrome／Edge 桌面扩展：进入 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，加载解压的 `extensions/watch-sync` 文件夹。扩展尚未上架商店，需要手动安装。
4. 在一起看房间页点击扩展图标，再点「连接这个房间」。稍候点「打开影片并授权」，仅授予当前视频网站的访问权限。扩展会打开一个受控播放标签页；此前手工打开的网页不受控。
5. 完成登录、付费与广告后，在官方播放页左下角点击「我已进入正片，开启同步」。所有人确认同一集正片后，由房主在一起看设置起点秒数并点击「一起播放」。广告期间务必先停止同步。
6. 播放、暂停和时间在一起看操作；网站上手动拖动不会反向广播。想改片，房主用「更换网站影片」，每人重新通过扩展打开新片并确认。切回本地影片需重新选文件；检测失败保留网站影片。

## 支持范围

| 网站 | 接受的播放页 | 状态 |
|---|---|---|
| 哔哩哔哩 | `www.bilibili.com/video/BV…/` 或 `av…/`，保留分 P 参数 `p` | 已实现标准网页播放器适配，尚未完成真实站点测试；暂不支持番剧页 |
| 优酷 | `v.youku.com/v_show/id_….html` | 同上 |
| 爱奇艺 | `www.iqiyi.com/v_….html` | 同上 |
| 腾讯视频 | `v.qq.com/x/cover/….html` 或 `x/page/….html` | 同上；所有人自行确认同集 |

只接受 HTTPS、无用户名密码和非默认端口的精确域名。除 B 站分 P 外清除查询参数及 fragment。短链需要用户先在浏览器打开后复制完整播放页，服务器不解析重定向、不抓取网页、不代理视频。

自动适配仅操作当前页面中唯一、可见且有有限时长的标准 video 元素；跨域 iframe、封闭播放器、直播、无法控制的 DRM 播放器及客户端专属内容不支持。播放器更换、时长改变、地址／媒体代次变化会停止同步；广告不保证能自动识别，必须由用户确认正片并手动停止。不会移除广告、解密视频、获取媒体地址或复用他人会员。

后台标签页限速、网站播放器行为和广告长度可能影响同步。扩展每秒更新一次；持续播放偏差超过 1.2 秒时校正，暂停和跳转按 0.15 秒容差对齐。这些是校正阈值，实际同步效果仍需在各网站测试。保持一起看页打开；超过 5 秒未收到房间状态时，扩展会在下一次检查时暂停播放器。断线、退出、被移除或房间结束后，需要重新开启同步。

视频不经过一起看，也不提供语音通话。音量、清晰度和字幕在官方网站分别调整。手机浏览器无法使用此桌面扩展，可以手动对齐；暂不支持自动切集和网站内浮动聊天。

## 权限与数据

Manifest V3 扩展只声明 `activeTab`、`scripting`、`storage`，四个官方域名作为可选权限逐站请求；没有 `<all_urls>`、Cookie、请求拦截、下载、录屏或服务器网络权限。自托管一起看的 HTTPS 域名通过用户点击扩展获取 activeTab 临时授权；本机也允许 localhost／127.0.0.1 HTTP。房间刷新后需要重新连接扩展。

配对保存在浏览器 session storage，只包含一起看标签页 ID、房间 ID、目标标签页 ID、经过清理的 URL、时间和版本，不持久保存账号或观看历史。扩展不接收房间 Cookie／邀请／LiveKit 凭证，不向任何第三方服务发送信息。只接受已配对房间标签页的快照，并只向已配对视频标签页返回；页面不能通过扩展命令获得房主控制权限。一起看同源页面脚本及用户安装的扩展属于信任边界，站点权限可在浏览器管理页撤销。

## 平台规则与测试情况

此扩展不是平台官方产品。账号、会员和内容权限由各平台管理，使用时请遵守相应服务规则：

- [B 站大会员协议](https://www.bilibili.com/html/big_protocol.html)
- [优酷会员服务协议](https://svip.youku.com/trade/subscribeagreement)
- [爱奇艺服务协议](https://www.iqiyi.com/common/loginProtocol.html)
- [腾讯视频用户服务协议](https://rule.tencent.com/rule/399ab3d0-4989-4f34-9d7b-99c579b4cbdf)
- [Chrome content scripts 官方文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)

自动化测试使用 Chromium、Redis 和本地视频样片，在模拟播放页检查同步脚本。四个平台的登录、会员播放、广告、扩展安装和公网同步尚未完成测试，因此目前仍标为实验功能。详细结果见[测试报告](TEST_REPORT.md)。
