# 本地验证报告

日期：2026-10-15。当前交付是 v0.1 本地可运行版本，**尚未完成整个公网产品验收**。生成美术、设计参考图、构建成功均不作为音画验证证据。

## 环境与版本

- Windows，Node.js 24.15.0；Vite 7.3.7、Vitest 5.0.4、Playwright 1.64.1。
- 测试使用本机已有 Chromium revision 1234，通过 PLAYWRIGHT_EXECUTABLE_PATH 指定；未把它描述为 Playwright 默认配套的 revision 1248。
- 原生 LiveKit Server v1.13.10，下载包 SHA-256 已与官方校验清单核对。
- 隔离 Redis 7.0.15，位于已有 WSL Ubuntu 发行版，端口 16379，禁用持久化；实际浏览器回归的控制服务使用此 Redis。
- 所有浏览器上下文及 SFU 均在同一台 Windows 机器、loopback 网络；不代表跨城或公网结果。

## 连续播放与补充回归

独立运行的两分钟连续播放通过：120.251 秒，12 次采样的解码帧持续增长，最后累计 1731 帧，始终保有电影音频和视频两条接收轨。V8 JS 堆首末采样约 35.2MB / 32.4MB，仅供短测观察，不代表 GPU 内存或长期无泄漏。控制断网重连、房主刷新重新选片、WebGL 禁用时静态降级也通过。

字幕追加实播验收曾发现固定字号／边距不适合小尺寸视频，已改成比例缩放；修复后观看端实际画面底部字幕像素检查通过，不以房主本地文字叠层代替。

两小时连续播放 **尚未执行**，不能由两分钟结果外推。

重复回归曾触发开发服务的每 IP 每小时 20 次建房限额；最终回归使用重新启动的服务，未放宽产品限流。暂停检查验证画面差不超过 500ms 且停止变化；实时编码器可能保留邻近帧，不要求双方冻结在完全相同的帧编号。

## 待验收及明确限制

- 两小时真实播放、反复换片、长时间音画漂移／内存增长／残留媒体轨检查。
- 真正跨网络 2/4/8 人、限速丢包、UDP 封锁、强制 TURN、手机切网／后台恢复。
- 真实 Chrome/Edge 之外的 Firefox、Safari、iOS、Android 音画与捕获兼容性；本机手机视口不等于手机实测。
- 大文件、更多编码／多音轨、损坏容器、字幕编码样本与完整恶意输入集合。已实现格式探测与边界控制，不承诺通用播放器兼容性。
- 真实麦克风、扬声器／耳机回声与听感；自动化使用浏览器虚拟音源及电影测试音。
- SFU 对恶意重复发布、旧令牌重建空房、跨房间接入的部署级对抗；目前有最小权限、代次隔离、退役重试、签名 webhook 与周期检查。
- 整栈容器运行、镜像安全扫描、真实 HTTPS/WSS、TURN/TLS、反向代理可信地址策略、正式运维配额与秘密扫描流程。
- 完整键盘／读屏人工测试、真实低端设备性能和 WebGL 故障矩阵。
- Jellyfin、个人字幕、多音轨切换、PiP、原生桌面／手机应用不属于本轮已完成能力。
- 短暂断线恢复控制快照后，媒体断开时须点击重新开始；房主刷新后须重新选择文件。没有浏览器文件权限的自动恢复承诺。
- 未购买账号或域名，未公开部署，未向 GitHub 推送或创建仓库。
