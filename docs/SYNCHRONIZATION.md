# 播放同步

每台设备独立解码自己的影片。房间传送播放、暂停、跳转及成员状态，不传送音视频。

连接建立时发送五次校时探测，用较低往返时延的样本估计服务端时间，每三十秒重新校时。目标进度按权威时间线计算。

| 偏差 | 处理 |
| --- | --- |
| 不超过 150ms | 保持原速 |
| 150—500ms | 暂时使用 0.97 或 1.03 倍速 |
| 超过 500ms | 跳转到目标位置 |

房主明确暂停和跳转时立即对齐。文件检测、缓冲、自动播放被阻止、断线和页面后台恢复分别处理；个人缓冲不暂停全房间。重新连接后需主动继续观看。

所有本地成员选择同一剪辑版本。时长相差超过一秒时拒绝准备，但相同时长不证明内容相同，仍需本人确认。

网站模式由扩展在官方页面执行操作，广告和会员播放需要各自处理。网站校正阈值与浏览器限制见[网站说明](WEBSITE_WATCH.md)，不将本地同步测量当作网站实测。
