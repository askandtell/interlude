Windows、Node.js 24.15.0，Vite 7.3.7、Vitest 5.0.4、Playwright 1.64.1。使用本机已有 Chromium revision 1234，通过 PLAYWRIGHT_EXECUTABLE_PATH 指定，并非 Playwright 默认配套的 revision 1248。原生 LiveKit Server v1.13.10，隔离 WSL Redis 7.0.15（16379，禁用持久化）。控制服务实际使用 Redis。
