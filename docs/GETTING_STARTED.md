# 和朋友一起看

## 本地影片

1. 创建房间并选择影片。影片只在你自己的设备播放，不会发送给朋友。
2. 复制“邀请朋友”的完整链接；朋友填写昵称并申请加入，你在“查看申请”中批准。
3. 朋友各自选择同一部、同一剪辑版本的文件。时长相差超过一秒时需要重新选片；时长相同也请自行确认内容一致。
4. 朋友确认版本后点击“加入一起看”，房主点击“开始放映”。迟到的朋友会加入当前进度。

房主控制共同播放、暂停和跳转。成员可以在聊天中发送“等我一下”；个人缓冲不会暂停所有人。电影音量和字幕由各自调整。

刷新后重新选择文件。房主可以确认从本机记录的位置续播；成员重新加入共同进度。断线恢复后，点击播放按钮继续。转交房主不转交文件。

## 视频网站

每个人各自在官网使用自己的账号和观看权限。自动同步需要桌面 Chrome/Edge 扩展，手机可以看房间时间并手动对齐。安装和广告处理见[网站模式](WEBSITE_WATCH.md)。该功能仍为实验性。

## 本机试用

安装 Git、Node.js 24+，克隆仓库后执行 `npm ci` 和 `node scripts/setup-dev.mjs`。分别启动 `npm run dev`、`npm run ui`，打开 http://127.0.0.1:15173 。本机网址只能在这台电脑使用；分享给远处朋友需要 HTTPS 部署。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 没有影片可看 | 每个人都需要自己的本地文件，或官网观看权限 |
| 申请后没有进入 | 等房主批准，检查房间控制连接 |
| 播放受阻 | 点击“继续观看”，检查浏览器是否允许声音和自动播放 |
| 时长不匹配 | 重新选择同一剪辑版本，不要混用片头、广告或删减不同的版本 |
| 断线后暂停 | 恢复房间状态后主动继续，不会自动恢复播放 |
| 网址首次打开很慢 | 免费托管可能正在唤醒；网络也可能暂时不可达 |

反馈时提供系统、浏览器版本和复现步骤。不要上传影片、完整邀请、Cookie、密钥或私人聊天。

自行建立网址见[托管说明](FREE_HOSTING.md)。普通使用者无需配置服务器或密钥。
